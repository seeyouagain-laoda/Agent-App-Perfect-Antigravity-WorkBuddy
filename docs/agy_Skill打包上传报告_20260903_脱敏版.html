② 收编时发现并修掉的 3 个真 bug（重要）

问题现象修复
端口硬编码 9333agy 每次启动端口都变（实测 9333 → 11182），重启后所有脚本静默失效动态读 DevToolsActivePort；且 APPDATA 在 Git Bash 子进程可能不导出 → 用三种基址候选回退
localhost 走系统代理连死端口返回 HTTP 502 Bad Gateway，伪装成"服务异常"，真因是 ECONNREFUSEDurllib 用 build_opener(ProxyHandler({})) 绕过代理
CDP recv() 无超时脚本永久卡死，只能靠外部 timeout 杀所有 recv 加 asyncio.wait_for(10~12s)，connect 设 open_timeout
